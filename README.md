# الري الذكي — Smart Irrigation

واجهة عربية لمراقبة رطوبة عبوتين والتحكم بمضختين عن بُعد، باستخدام ESP32 NodeMCU وخادم HiveMQ Cloud.

## المزايا

- عرض نسبة الرطوبة وقراءة RAW لكل حساس.
- تشغيل وإيقاف المضختين من شاشة واحدة.
- تشغيل الري التلقائي وتغيير حد بدء الري لكل عبوة.
- عرض حالة الاتصال وتعطيل الأوامر عند انقطاع البيانات الحية.
- إدخال بيانات MQTT من نافذة الاتصال دون كتابتها في ملفات الموقع.

## ملفات المستودع

| الملف | الوظيفة |
|---|---|
| index.html | واجهة التحكم، وتشمل HTML وCSS وJavaScript |
| README.md | شرح المشروع والتشغيل |
| .nojekyll | تعطيل معالجة Jekyll |
| .gitignore | استثناء ملفات البرنامج والأسرار عند استخدام Git |

تُحمّل مكتبة MQTT.js بالإصدار 5.10.4 من jsDelivr عند فتح الصفحة؛ يلزم اتصال الجوال بالإنترنت.

## المتطلبات

1. ESP32 عليه برنامج Smart_Irrigation_Internet.ino المتوافق مع هذه الصفحة.
2. اتصال ESP32 براوتر Wi-Fi متصل بالإنترنت.
3. خادم HiveMQ Cloud، واسم مستخدم MQTT وكلمة مرور بصلاحية النشر والاشتراك.
4. معرّف الجهاز من صفحة ESP32 المحلية أو Serial Monitor.

## إعداد ESP32

- أدخل بيانات خادمك في MQTT_HOST وMQTT_USER وMQTT_PASSWORD داخل برنامج ESP32.
- ارفع البرنامج إلى المتحكم من Arduino IDE.
- اتصل بشبكة SMART_IRRIGATION وكلمة المرور Irrigate2026.
- افتح http://192.168.4.1، ثم اختر شبكة الراوتر وأدخل كلمة مرورها.
- انسخ معرّف الجهاز كما يظهر؛ مثال توضيحي: irrigation-12345678.

إعداد Wi-Fi ومعايرة الحساسين يتمان من واجهة ESP32 المحلية. برنامج ESP32 يُرفع إلى اللوحة من Arduino IDE؛ ملفات هذا المستودع مخصصة للموقع.

1. ضع الملفات الأربعة في جذر مستودع GitHub عام.
2. افتح Settings ثم Pages.
3. اختر Deploy from a branch ثم main ثم /(root)، واحفظ.

## الاتصال من الجوال

1. افتح الموقع واضغط «الاتصال».
2. أدخل مضيف HiveMQ Cloud دون https:// أو رقم منفذ.
3. أدخل معرّف الجهاز واسم مستخدم MQTT وكلمة مروره.
4. اضغط اتصال وانتظر وصول بيانات حية وتفعيل أزرار التحكم.
5. اختبر باستخدام بيانات الجوال للتأكد من التحكم خارج الشبكة المحلية.

## الاتصال والتشغيل

- ESP32 يستخدم MQTT TLS على المنفذ 8883.
- المتصفح يستخدم WSS على المنفذ 8884 والمسار /mqtt.
- المواضيع تُنشأ تلقائيًا تحت irrigation/DEVICE_ID، وتشمل state وcommand وack.
- كلمة مرور MQTT تختلف عن كلمة مرور Wi-Fi وعن كلمة مرور حساب GitHub.
- لا تكتب كلمات المرور في ملفات المستودع. الصفحة لا تحفظها في localStorage أو sessionStorage.
- فصل الصفحة لا يوقف المضخات؛ يستمر برنامج المتحكم المحلي.
- قد تثبت قراءة الرطوبة مؤقتًا أثناء تشغيل المضخات، وتوضح الواجهة ذلك.
- النسبة المعروضة تعتمد على معايرة كل حساس، وليست قياسًا مخبريًا لمحتوى الماء.
- هذه الواجهة لم تُختبر مع دائرتك الفعلية بعد.
